# P0/P1/P2 이슈코드

**분류**: concept · 이슈 분류 체계

## 한 줄 정의
- 입력 계획서(코옵 Netcode 실행계획)가 네트워크 이슈를 **심각도 순으로 분류한 라벨** — P0(치명: 동작 자체가 틀어짐) > P1(중요: 규약·일관성 결함) > P2(개선: 효율·소음·고도화). 뒤 숫자는 일련번호(예: P2-4 = 패킷 로그 소음).

## 쉬운 설명
> 병원 응급실의 중증도 분류(빨강/노랑/초록)와 같다. 빨간 환자(P0)부터 치료하듯, P0 이슈부터 고친다. "P2-4 채널화"처럼 문서 곳곳에 등장하는 코드는 전부 이 분류표의 이슈 번호다.
