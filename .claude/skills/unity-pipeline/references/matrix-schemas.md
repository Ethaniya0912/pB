# 매트릭스 스키마 — 단일 진실원

> 각 단계 매트릭스의 컬럼 정의. 템플릿(`assets/templates/0N_*.md`)이 이 스키마를 따른다.
> 드리프트 방지: 컬럼을 바꾸려면 **여기서 먼저** 바꾸고 템플릿을 맞춘다.
> 모든 단계는 매트릭스와 함께 **Mermaid 다이어그램**(_conventions §13-A)을 둔다 — 표는 데이터, 그림은 관계.
> 참조되는 ID(T·G·A·게이트)에는 `<a id>` 앵커를 달고 점프 링크로 잇는다(§7-A).

## ① target 매트릭스 (`01_target.md`)
| 컬럼 | 의미 |
|---|---|
| `T-ID` | target 식별자 (T1, T2, …) |
| `항목` | 기획 항목 한 줄 요약 |
| `분류` | 기능/시스템/콘텐츠/UX/제약 등 |
| `원문근거` | 출처 문서·위치(인용 또는 페이지/섹션) |
| `해석` | SE 관점 해석(원문과 구분) |
| `모호도` | 낮음/보통/높음 — 높음은 G1 에서 질문 |

## ② goal 매트릭스 (`02_goal.md`)
| 컬럼 | 의미 |
|---|---|
| `G-ID` | goal 식별자 (G1, G2, …) ※ 게이트 G와 무관 |
| `연결 target` | 매핑된 T-ID(들) |
| `개발 요구사항` | 구현 가능한 단위로 변환된 요구 |
| `필요 시스템` | 관련 시스템/모듈 |
| `에셋 범주` | Script/Prefab/Scene/Data/Material/… (`_conventions.md` §2) |
| `우선순위` | P0/P1/P2 |

## ③ scope 매트릭스 (`03_scope.md`)
| 컬럼 | 의미 |
|---|---|
| `연결 goal` | G-ID |
| `상태` | 기구현 / 신규 / 변경 |
| `대상 에셋·타입` | 확인된 클래스/에셋 경로 |
| `존재 근거` | unity-cli exec 결과 / 이전 사이클 참조 |
| `영향 범위` | 영향받는 시스템·씬·프리팹 |

## ④ assets 매트릭스 (`04_assets.md`)
| 컬럼 | 의미 |
|---|---|
| `A-ID` | 에셋 식별자 (A1, A2, …) |

| `범주` | Script/Prefab/Scene/Data/Material/… |

## ⑤ spec (에셋 단위, `05_spec/<A-ID>_<에셋명>.md`)
- **공통(맨 앞):** 쉬운 설명(비개발자용 1~3문장, `[[용어]]` 링크).
- **스크립트:** 클래스명·책임(1문장)·공개 API(시그니처)·인터페이스·의존성·수명주기.
- **비스크립트:** 사양(필드/설정값)·포맷·제약·참조 관계.

## ⑥ test_env (`06_test_env.md`)
| 컬럼 | 의미 |
|---|---|

| `to-be` | 목표 상태(unity-cli 실행 가능 수준으로 구체) |

## ⑦ plan 체크리스트 (`07_plan.md`)
- 형식: `- [ ] <task>` (미완료) / `- [x] <task>` (완료). Stop 훅이 미체크 수로 판정.
- 각 task 는 **연결 A-ID** 와 **검증 방법**(compile/play/console)을 한 줄에 포함 권장.

## ④ assets — 상태값 확장 + Hierarchy 배치
- `신규/변경/삭제` 열: `new` / `modify` / `delete`. 손대지 않지만 활용하는 기존 에셋은 매트릭스 밖
  또는 Mermaid 의 keep 노드로 표현.
- **Hierarchy 배치 표**(§15): `A-ID | 배치 유형(씬배치/DDOL/프리팹/런타임 자동생성) | 경로·방식`.
  자동생성은 "씬 배치 없음 — 런타임 자동생성"으로 명시.

## ⑤ spec — 산출물 사용 가이드 (§16)
- 쉬운 설명 + 기술 명세 + **산출물 사용 가이드**(언제·왜 / Unity 적용법 / 사용법 / 주의점).

## ⑥ test_env — to-be Hierarchy
- 매트릭스 + 적용 스니펫 + **to-be Hierarchy 트리**(레이어→그룹→GO, 자동생성 명시).

## ⑧ result (`08_result.md`)
- 요약 · 완료 goal/target 대비표 · as-is→to-be diff(에셋 실링크) · **검증 증빙** · **다측면 이점** · 잔여 이슈 ·
  게이트 결정 요약(decisions.md 링크) · 용어 사전 갱신.
- **검증 증빙 스키마** (`_conventions.md` §10):
  - 검증 환경·시각 표: `항목(검증 일시/Unity·Connector/검증 방법) | 값`
  - task별 검증 기록 표: `task(A-ID) | 시각 | 방법 | 판정 | 근거(evidence/ 링크)`
  - 콘솔 로그 발췌(```log) + 스크린샷 임베드(`![..](evidence/..png)`) + 산출물 실링크.
- **다측면 이점 표** (`_conventions.md` §14): `측면(게임/개발/기획/아트/운영) | 이점`.
- **산출물 인수인계 표** (`_conventions.md` §16): `산출물 | 무엇 | 적용(자동/수동) | 사용법 한 줄 | 주의`.
