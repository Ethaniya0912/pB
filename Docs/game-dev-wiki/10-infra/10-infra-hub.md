# 10 · 서버 호스팅 인프라

전용 서버 없음. Steam P2P 중계 + 호스트 권위 P2P 방식이 현재 인프라의 전부다.

## 문서

- [[server-hosting|서버-호스팅]] — P2P 현황, 전용 서버 미구축, 호스트 이탈 리스크

## 핵심 현황 요약

| 항목 | 현황 |
|---|---|
| 서버 방식 | Steam P2P 중계 (전용 서버 없음) |
| 호스팅 비용 | 0 (Steam 중계 무료) |
| 매치메이킹 | Steam 로비 수동 탐색 |
| 지역 배치 | 미구현 |
| AppID | 480 (테스트용, 실 앱 ID 미등록) |

## ⚠ 가장 중요한 리스크

호스트 이탈 = 세션 소멸. EA 출시 전 이 트레이드오프를 스팀 페이지에 명시하거나, 전용 서버 ADR을 수립해야 한다.
