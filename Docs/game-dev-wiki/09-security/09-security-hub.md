# 09 · 보안 / 안티치트

전용 안티치트 미구현. 호스트 권위 모델이 유일한 방어선이며 호스트 자체 치팅은 원천 방어 불가다.

## 문서

- [[anti-cheat|안티치트]] — VAC/EAC/BattlEye 미도입, P2P 호스트 치팅 방어 불가

## 핵심 현황 요약

| 항목 | 현황 |
|---|---|
| 안티치트 SDK | 미도입 |
| 호스트 권위 | 구현 중 (R6 Step 2 진행) |
| 입력 sanity check | 미구현 |
| 민감 데이터 서버 보관 | 미구현 (로컬 저장) |
| VAC 활성화 | 미결정 |

## ⚠ 가장 중요한 리스크

P2P 호스트 = 호스트 플레이어가 곧 서버. 호스트 치팅은 현재 구조로 방어 불가. EA 전 방향 결정 필수.
