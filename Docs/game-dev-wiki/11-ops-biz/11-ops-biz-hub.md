# 11 · 운영 & Steamworks 행정

Steam AppID 480(테스트용) 개발 단계. 실 AppID 미등록, SteamPipe 자동화 없음.

## 문서

- [[steamworks-admin|steamworks-행정]] — AppID 480, 파트너 행정 체크리스트, SteamPipe 미자동화

## 핵심 현황 요약

| 항목 | 현황 |
|---|---|
| Steamworks SDK | Facepunch.Steamworks 적용 완료 |
| AppID | 480 (Spacewar 테스트용) |
| 실 AppID | 미등록 |
| SteamPipe 업로드 | 수동 |
| Steam Cloud | 미구현 |
| 실적(Achievement) | 미구현 |

## ⚠ 가장 중요한 리스크

실 AppID 미등록 = Steam 릴리즈 불가 상태. EA 전 Steamworks 파트너 포털 신청($100)이 필수 선행 작업이다.
